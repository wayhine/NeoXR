# 媒体库视图与排序

本地媒体库、SMB 和 WebDAV 共用这套界面。

- **视频视图**：显示当前媒体库或目录内所有视频（包括子目录），保留缩略图。
- **文件夹视图**：先显示保存的媒体库目录；点击后逐层显示子目录和当前层视频。
  “上一级”逐层返回，顶部路径显示当前所在位置。只列出媒体索引中有视频的子目录。
- **搜索**：视频视图搜索视频标题；文件夹视图也匹配文件夹名、路径及内部视频名。
- **排序**：名称、创建时间、文件大小、时长都支持升序和降序。文件夹始终排在视频前面。
  缺失的数值或时长在升降序中均排最后，数值相同则按名称及路径保持稳定顺序。
- **文件夹排序值**：按内部视频的最新时间、视频总大小或视频总时长计算；
  卡片显示视频数量和视频总大小。空根目录仍可进入，未收录视频的子目录不显示。
- **时长**：选择时长排序后在后台读取当前范围的视频时长并缓存，显示读取进度。
  最多两路读取；离开媒体库会停止继续批量读取。大量条目先显示进度，完成后更新排序。
  不支持的视频或网络错误会显示未知并排最后。“管理 → 重新扫描”可重新尝试失败信息。
- **保存**：视图、排序字段和升降序会保存。本地和各个网络设备的选择相互独立。

SMB 使用服务端创建时间；WebDAV 使用 `DAV:creationdate`。本地 Android 文件夹选择器
不统一提供创建时间，无法获取时按修改时间排序，并在界面提示，不用修改时间冒充创建时间。
旧索引可正常恢复，重新扫描会补充网络目录提供的新字段。时长缓存仍按视频地址、大小和修改时间失效。

手机验收：用大量多层目录切换视图、搜索目录和标题，验证返回上一级、筛选目录及排序。
检查创建时间/大小/时长的两种顺序，网络断开、部分视频无法解码、退出和重新打开的行为。
同时验证眼镜菜单和窄屏、大字体布局。

参考：[Android DocumentsContract.Document](https://developer.android.com/reference/android/provider/DocumentsContract.Document)、
[WebDAV creationdate](https://www.rfc-editor.org/rfc/rfc4918.html#section-15.1)。
