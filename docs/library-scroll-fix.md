# 媒体库顶部栏目滚动修复

适用版本：`1.6.0-community.2`（versionCode `8`）。

本文记录.2版本的修复。当前.4版本已改为整页滚动，取消自动收起与浮动展开按钮，触控板可从顶部栏目区域滚动，见[当前版本说明](releases/v1.6.0-community.4.md)。

## 原因

旧逻辑在嵌套滚动的预处理阶段，同时优先消耗两个方向的滑动距离。
因此，即使视频列表已经滚到中间，反向滑动也会先展开顶部栏目，再把剩余距离交给列表。
横屏下顶部栏目较多，列表可见空间随之变小，表现为视频区只在底部缓慢移动。

此外，每个滑动事件都会请求整块媒体库重新布局，并反复测量父容器和网格尺寸，
造成栏目出现、消失时的卡顿与尺寸跳变。

## 修改

- 向后浏览视频时先收起顶部栏目，然后滚动视频。
- 返回前面的视频时优先滚动列表；到第一行之后，剩余滑动距离才用于展开栏目。
- 网格一次测量到栏目完全收起时的可用尺寸；栏目展开时由父容器裁剪多余部分。
- 手势过程中只移动内容位置，避免按像素重新测量和绑定视频卡片。
- “筛选 / 排序”入口随收起距离渐显；点击后以 180 毫秒动画展开。
- 新手势和页面离开时取消未完成的展开动画。

本地、SMB 和 WebDAV 媒体库复用同一布局组件，因此采用相同交互。

## 手机与眼镜验收

1. 在本地或网络媒体库中，先滚动到较后面的视频。
2. 反向滑动时，视频列表应立即移动，顶部栏目保持收起。
3. 回到第一行后继续滑动，顶部栏目才逐步展开。
4. 在两个方向来回缓慢滑动，栏目和视频区应连续移动，不再反复改变网格尺寸。
5. 点击“筛选 / 排序”，检查展开动画；动画过程中开始滚动，确认能立即接管操作。

安装包仍输出到 `app/build/outputs/apk/debug/NeoXR.apk`，可使用原来的 `adb install -r` 命令覆盖安装。
