# 手机单画面双指缩放

适用版本：`1.6.0-community.3`（versionCode `9`）。

## 操作

在手机上以“输出：单画面”播放视频时，将两根手指放在视频画面区域：

- 双指张开：放大。
- 双指捏合：缩小。
- 范围为50%–300%，缩放时显示当前百分比。
- 松开后保留当前缩放，重新打开视频从100%开始。

普通视频按比例、以画面中心缩放；VR 视频通过调整视野缩放。
缩放与现有的“缩放”加减按钮使用同一比例。

## 手势兼容

- 在“调整视角”和“调整进度”两种单指设置下均可使用双指缩放。
- 第二根手指加入后，取消未提交的进度预览，结束临时长按倍速并恢复原速。
- 双指操作期间停止单指视角、进度、音量和亮度手势；抬起其中一根后，剩余手指继续受到保护。
- 全部手指松开，下一次单指触摸恢复原有操作。
- 切换输出、旋转、失去焦点或切后台时结束正在进行的双指缩放；取消手势不会复原已经调整的缩放比例。

本手势限视频在手机单画面输出时使用。连接眼镜后的手机控制器、手机 SBS 双屏和手势设置面板不启用双指缩放。

## 验收

1. 播放一个普通横屏视频，以单画面输出，双指张开和捏合，检查画面比例及缩放提示。
2. 换一个竖屏视频和 VR180 视频，重复操作，检查缩放及边界。
3. 在调整进度模式下先开始进度预览，再加入第二根手指，确认松开后没有提交原预览位置。
4. 在长按倍速状态加入第二根手指，确认恢复原速；放下一根手指后移动剩余手指，确认没有误调进度、亮度或音量。
5. 旋转或切后台后重新开始双指缩放，确认新手势没有突然跳变。

APK 输出位置仍为 `app/build/outputs/apk/debug/NeoXR.apk`，签名沿用此前二开版本，可覆盖安装并保留媒体库。
