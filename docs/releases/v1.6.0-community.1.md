# NeoXR Community Fork 1.6.0-community.1

这是基于 [NeoXR-app/NeoXR](https://github.com/NeoXR-app/NeoXR) 1.5 的首个社区二开整理版本，
由 [wayhine](https://github.com/wayhine) 维护，非上游官方发行版。

Android 版本：`versionName=1.6.0-community.1`，`versionCode=7`。

## 主要更新

- 本地、SMB、WebDAV 缩略图媒体库：递归扫描、保存恢复、搜索、文件夹浏览与排序。
- 中文界面、长按最高 6× 临时倍速、滑动进度／亮度／音量、横竖屏控制。
- 手机与眼镜默认单画面输出，可按眼镜显示模式切换 SBS。
- 修复媒体库切换播放器时的眼镜窗口交接，改进外接屏重连与渲染恢复。
- 改进 One / 1S 头控数据读取及连接恢复，增加无线 ADB 日志采集工具。

完整变更见 [CHANGELOG.md](https://github.com/wayhine/NeoXR/blob/community/CHANGELOG.md)。

## 下载和安装

下载本页附件 `NeoXR.apk`，适用于 Android 8.0 及以上、ARM64 设备。
本 APK 为使用既有本地调试密钥签名的 Debug 构建；相同包名和相同签名的旧二开版本可覆盖安装，
保留媒体库和设置。其他来源安装包是否能覆盖，以 Android 的签名校验结果为准。
附件 `SHA256SUMS.txt` 用于核对下载文件。

对应源码由本 Release 的 `v1.6.0-community.1` 标签及下方 Source code 附件提供。
构建需要 JDK 17、Android SDK 35 和仓库中的 Gradle Wrapper，运行 `./gradlew assembleDebug`。
