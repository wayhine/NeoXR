# NeoXR 社区版 1.7.0

更新日期为2026-11-18，Android versionCode为11。

## 雷鸟GT头控

- 增加GT的USB授权、传感器连接及SDK姿态读取，沿用播放器的头控、灵敏度与回正入口。
- 在OPPO Find X9 Pro上实测约302秒，取得140752次IMU回调，平均约467次/秒。
- 固定手机、单独转动眼镜，确认数据来自GT。用户已确认视频播放与眼镜头控方向正常。

## 手机陀螺仪

- 手机与眼镜分别保存灵敏度，手机默认50%，可在“画质”中调整。
- 修复手机接近平放时的左右抖动，以及关闭眼镜头控后切回手机时的基准跳变。
- 用户已确认修复后的手机陀螺仪手感正常。

## 网络媒体库切换

首页进入SMB／WebDAV网络媒体库时，在现有外屏窗口内切换内容。实机捕获到的OPPO新窗口拒绝问题通过这条路径解决，外屏直接显示文件夹视图。

保留文件夹、搜索、排序及缓存，并支持系统返回和页面重建恢复。GT实机录屏往返两次，期间窗口显示、隐藏及拒绝均为0次，画面没有露出手机控制界面。
