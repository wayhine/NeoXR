# WebDAV 媒体库

1. 主页选择“网站 / 网络”，点击“添加 WebDAV 媒体库”。
2. 填写服务端提供的完整 HTTP / HTTPS 目录地址，以及用户名、密码。
   例如 `https://nas.example:8443/dav/`；公开目录可以留空账号密码。
3. 点击“添加”后浏览目录，选好位置再点“添加此目录”。当前入口目录也能直接添加。
4. 应用递归扫描视频，显示缩略图、标题和时长。可按目录筛选、搜索、播放及续播。
   下次进入自动恢复保存的媒体库，后台刷新；扫描失败保留已有记录。
5. “管理”中可添加其他子目录、重新扫描或移除记录。所有操作均为只读，不修改服务器文件。

原地址输入框仍支持网站和 SMB，也接受
`webdav://用户名:密码@主机:端口/路径/`（HTTP）或
`webdavs://用户名:密码@主机:端口/路径/`（HTTPS）。建议使用填写框录入账号密码，
应用会处理特殊字符编码。普通 `https://` 在原输入框中仍按网站处理。

当前支持公开访问及 Basic 用户名密码认证。HTTPS 使用 Android 系统信任的证书。
目录读取使用 PROPFIND / Depth: 1；服务端应提供标准的 DAV multistatus 响应。
播放、拖动进度和缩略图使用 HTTP Range 读取；不支持范围读取的服务器无法正常跳转
或提取需要随机访问的视频封面。Digest、网页登录及客户端证书认证暂不支持。

连接及索引保存在应用私有存储中；标题和列表地址不显示账号密码。
缩略图和时长复用私有的代理文件描述符，预读缓存 256 KiB，最多同时两路预览，
每个预览读取预算 64 MiB。不会为了生成封面而先完整下载视频。
视频格式或编码不被系统支持时显示占位图，仍可点击尝试播放。
跨主机的视频下载重定向不会携带原服务器的登录信息，HTTPS 不降级到 HTTP。

## 验证

自动测试用本机 HTTP 服务实际验证 PROPFIND、Basic 认证、中文和特殊字符文件名、
递归扫描、保存恢复、权限错误保留缓存、分段读取、随机预览、读取预算和重定向凭据隔离。
手机连接实际 NAS 后还需确认缩略图解码、时长、续播、拖动进度、离线恢复和眼镜控制。

协议参考：[WebDAV / RFC 4918](https://www.rfc-editor.org/rfc/rfc4918.html)、
[HTTP 范围读取 / RFC 9110](https://www.rfc-editor.org/rfc/rfc9110.html#name-range-requests)。
