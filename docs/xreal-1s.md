# XREAL 1S：媒体库横屏、视频输出和头控

## 使用方式

- 本地、SMB、WebDAV 媒体库都可向上滑动网格，收起从页面标题到搜索、视图、排序的整块顶部栏。向下滑动，或点击右上角“筛选 / 排序 ↓”，重新展开。短横屏首次进入时会适当收起顶部，给缩略图留出空间。网格仍按需加载，没有把整个媒体库放进 ScrollView。
- 手机控制器在媒体库页面用双指滚动，效果与直接滑动媒体网格相同。光标应在网格区域。
- 每次新打开媒体默认单画面，连接眼镜也可用单画面。在手机播放器的“立体 → 输出”中切换单画面和 SBS。
- **单画面**：眼镜的 3D 模式关闭。它是取一个眼睛的视角输出一个完整画面，眼镜在二维模式下把相同画面送给两眼，并非关闭某一侧镜片。
- **SBS**：眼镜选择与应用输出标签匹配的半宽 / 全宽模式，关闭 REAL 3D；常见 1920×1080 对应半宽，3840×1080 对应全宽。应用跟随当前显示时序，不再强制请求最大分辨率。1S 的 1920×1200 / 3840×1200 也使用相应的眼睛画面比例。
- 视频源的“左右 / 上下 / 二维”和“180° / 360° / 平面”描述视频的编码布局、投影；“输出”描述交给显示器的画面布局，两者分开设置。例如 VR180 SBS 源也可设置单画面输出，源布局仍选左右。
- 超宽分辨率也可能是眼镜的超宽二维模式，不能只凭分辨率认定眼镜已启用 3D。请按眼镜菜单确认。

## 模式切换和恢复

媒体库与播放器只在各自页面位于前台时显示眼镜窗口。进入播放器前会释放媒体库窗口；播放器等页面恢复到前台后再创建输出窗口。若系统暂时拒绝窗口，最多尝试三次，持续失败才退回手机播放，并在日志中保留异常堆栈。

眼镜切换模式时，Android 可能先移除外接屏、再分配新的屏幕 ID，也可能取消 Presentation 后重用原来的 ID。应用等待显示状态稳定再重建；外接屏消失后预留 4 秒重连时间，仍未恢复才回到手机。切换期间保存播放位置、暂停状态、投影和单画面 / SBS 选择；真正拔掉眼镜后手机恢复单画面。系统只重建 EGL 表面时，解码器也重新绑定到新的视频表面。

## 头控连接

1. 使用支持 USB-C DP 视频输出和 USB 网络的手机、数据线或转接器。DP 视频输出、USB 音频和 USB 网络是不同链路，显示正常不代表传感器可访问。
2. 更新眼镜固件；在支持的固件菜单中启用 TCP/IP / 以太网。不同固件菜单名称可能不同。
3. 眼镜使用跟随模式、关闭防抖，避免眼镜内置画面稳定和应用头控叠加。
4. 退出 Control Glasses、Nebula 或其他可能占用头控的应用；若有 VPN / 本地 VPN 广告过滤器，允许 NeoXR 绕过或暂时关闭后排查。
5. 播放器点击“头控”，收到有效数据后保持头部平稳片刻，再点击“回正”。

本版按本机 USB 子网优先尝试 `169.254.2.1:52998` 与 `169.254.1.1:52998`，依次使用对应本地地址、可用以太网 Network 及直接连接。只绑定头控套接字，避免将 Wi-Fi 上的媒体流量改到眼镜网络。

报文按固定长度 134 字节、`28/27 36 00 00 00 80` 头和偏移 30 的类型 `0x0b` 识别运动数据，跳过穿插的磁力计记录；不再把偏移 78 的固件相关字节当作类型。融合使用设备时间戳，避免 TCP 批量到达改变运动速度。收到有效报文才报告已连接，无有效报文会超时并重试；最终失败回到手机陀螺仪。

如果手机系统根本没有建立 CDC NCM / ECM 网络接口，应用无法单靠解析报文补上系统驱动，需要在该手机 / 固件 / 转接器组合上核实 USB 网络支持。

本次用户设备为 OPPO Find X9 Pro、Android 17，眼镜固件 `15.1.03.603_20260914_15.A.01.097_20250430_1.9.1.20260914175625`。本 APK 的 targetSdk 是 34；按照 Android 官方文档，Android 17 对 targetSdk ≤36 且声明 INTERNET 的应用仍隐式允许局域网访问，因此没有为此添加不适用的 ACCESS_LOCAL_NETWORK 弹窗。ColorOS 是否建立了眼镜的 USB 网络、是否有额外的应用联网限制，仍需这台真机的接口和连接日志确认。

## 验证

自动测试覆盖：短横屏、大字体、窄屏网格实际释放高度及筛选入口恢复；双地址优先级；1S 类型字段、备用报文头、TCP 分包、磁力计穿插、无数据超时；显示移除后重连、更换 ID、复用 ID 但 Presentation 被取消、真正拔出；16:9 / 16:10 和半宽 / 全宽画面比例。

仍需手机和眼镜实测：在一个本地视频上分别测试单画面+眼镜二维、SBS+半宽、SBS+全宽，播放与暂停时切换模式，观察位置、声音和画面是否恢复；然后测试头控、媒体库滚动和网络视频。程序没有发送未经验证的眼镜私有模式切换命令。

连接顺序也应分别验证：先连接眼镜，从媒体库打开视频；先在手机播放，再连接眼镜；播放后返回媒体库，再打开另一个视频。三种流程都应在眼镜显示内容，页面切换不应误触发拔出恢复，也不应留下旧媒体库窗口遮挡视频。

若头控失败，可用 Android SDK 的 adb 保存日志：

```powershell
adb logcat -s NeoXR -v threadtime
adb shell ip addr
adb shell dumpsys display
```

同时记录手机型号、Android 版本、眼镜固件、是否经过扩展坞和眼镜当前 3D 模式。
